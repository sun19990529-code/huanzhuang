# 巴黎法式 Ins 风格统一、多维服装筛选引擎与无缝影棚大画布重构实施方案

## 1. 项目背景与目标

根据用户明确选定的 **方案 1：巴黎法式 Ins 极简风 (Parisian Chic)**，本次重构将从视觉统一性、穿搭筛选检索效率与画布空间融合度三大维度进行全面升级：

1. **全局统一巴黎法式 Ins 极简设计系统 (Parisian Chic Visual System)**：
   - 告别生硬死黑与杂乱对比，全站统一为**暖奶油米杏底色 (`#FAF8F5` / `#F5F2EB`)**、法式复古豆沙玫瑰 (`#E17055` / `#D63031`)、精致 1px 细边框与柔和微阴影（Soft Ambient Shadow）。
   - 顶栏、左侧衣橱、右侧大画布、底部浮动工具栏、设置弹窗等所有组件 100% 像素级色系对齐。
2. **左侧 45% 衣橱多维智能筛选与检索引擎 (Garment Multi-dimensional Filtering)**：
   - **Row 1**：一级类目胶囊（全部 / 上装 / 下装 / 外套 / 鞋履 / 配饰）；
   - **Row 2**：常驻 12 色系色谱圆点（黑、白、灰、米杏、绿、蓝、红、粉、棕、紫、黄、多色），**支持多选过滤**；
   - **Row 3**：展开式高级筛选抽屉（细分类目多选：T恤、衬衫、西装、卫衣、短裙、牛仔裤、长裤、礼服；花纹多选：纯色、条纹、格纹、印花、碎花等）；
   - 搜索输入框模糊匹配；
   - 筛选条件在切换「我的专属衣橱」与「官方公共试衣间」时**无缝保持生效**，支持「一键清空重置」。
3. **右侧 55% 自由大画布无缝影棚融合与极简化 (Seamless Cyclorama Studio Canvas)**：
   - **消除割裂感**：彻底移除中间生硬的白底卡片边框，模特素体 100% 自然融入影棚底色，脚下增加真实漫反射柔和地影；
   - **9:16 安全画框**：采用极细的微光虚线透视引导，不挡视线，散落单品与模特真正同处一个连续的摄影棚空间；
   - **彻底瘦身**：**完全移除**画布底部的 `我自己 168cm / 58kg 修改身材` 黑色条，释放垂直视距。

## 2. 状态架构与筛选运算逻辑

```
[服装筛选状态矩阵 FilterState]
 ├── categories: GarmentCategory[] (一级大类)
 ├── colors: string[] (12色系多选，OR 关系)
 ├── subCategories: string[] (二级细分子类多选，OR 关系)
 ├── patterns: string[] (花纹多选，OR 关系)
 └── searchQuery: string (关键词模糊搜索)

[筛选解算规则]:
 FilteredList = AllItems.filter(item =>
   (CategoryMatch) && (ColorsMatch OR empty) && (SubCategoryMatch OR empty) && (PatternsMatch OR empty) && (SearchMatch)
 )
```
