# SmartWardrobe 标准素体生图、衣服抠图与解剖对齐重构方案

## 🎯 问题溯源与彻底解决方案

针对您在截图中指出的 **“人物没有生成标准化素图”、“衣服没有抠图”、“穿上身位置不对”** 3 个根本问题，我们完成了深度排查：

| 序号 | 暴露的问题 | 根本技术原因 | 本次彻底解决方案 |
| :--- | :--- | :--- | :--- |
| **1** | **人物未生成标准素图** | 上传接口错误地将用户带复杂背景、铠甲和动作的原图直接赋给了 `normalizedImageUrl` | **强制 AI A-Pose 素体重构**：接收用户照片后，后端强制调用 `gemini-3-pro-image`，生成一张**纯白底、正面直立、微张双臂（A-Pose）、穿贴身中性素衣**的标准模特图！绝不将原图当作素体。 |
| **2** | **衣服未抠图/带原背景** | 上传接口直接把用户包含背景和模特的整张原图赋给了 `assets.pngUrl` | **强制 AI 标准平铺图（Ghost Mannequin）生成**：Vision LLM 识别后，后端调用 `gemini-3-pro-image` 为单品生成**纯白底/透明底、正面无模特的标准平铺服装图**。 |
| **3** | **穿上身位置不对** | 画布绝对坐标偏移量没有与 A-Pose 模特的骨骼点（肩颈、胸腔、腰线、脚踝）精准锚定 | **标准骨骼坐标系锚定**：以 A-Pose 模特为统一基准（高 400px），上装领口精准对齐颈部（`top: 78px`）、下装腰头精准对齐腰线（`top: 195px`）、鞋子精准对齐脚踝（`top: 335px`）。 |

---

## 🏛️ 详细改造计划

### 1. 服务端 AI 服务全面打通 (`server/src/aiService.ts` & `server/src/index.ts`)
- **人物 A-Pose 素图生成器**：
  - `AIService.generateStandardMannequinFromPhoto(photoBase64, gender, heightCm, weightKg)`
  - 调用 `gemini-3-pro-image`，以原图特征为参考，生成纯白底、A-Pose、贴身素衣的标准身材素体。
- **衣服标准化平铺切片生成器**：
  - `AIService.generateGhostMannequinAsset(title, category, subCategory, colors)`
  - 调用 `gemini-3-pro-image`，生成电商级纯白底/透明底平铺图。
- **重写上传路由**：
  - `POST /v1/profiles/:id/avatar/upload`：调用人物标准化生图，将生成的标准 A-Pose 图赋给 Avatar。
  - `POST /v1/garments/auto-detect-upload`：先由 Vision LLM 识别，再对每件单品生成标准透明底切片。

### 2. 前端画布解剖学精准贴合重构 (`web/src/views/FittingStudioView.tsx`)
- 画布中央使用标准的 A-Pose 模特比例；
- 单品上身位置严格按照骨骼坐标系：
  - 头部配饰：`top: 12px; left: 50%; transform: translateX(-50%); width: 70px;`
  - 外套：`top: 76px; left: 50%; transform: translateX(-50%); width: 160px;`
  - 上装：`top: 80px; left: 50%; transform: translateX(-50%); width: 130px;`
  - 下装：`top: 195px; left: 50%; transform: translateX(-50%); width: 110px;`
  - 鞋履：`top: 335px; left: 50%; transform: translateX(-50%); width: 90px;`
